# agents.md: project briefing for any coding agent

## What this is
A cinematic, GTA VI inspired developer portfolio for K. Satya Sampath Kumar.
Layout and motion follow the workflow from the JavaScript Mastery video
"GTA 6 Took 13 Years. Your Portfolio Takes 30 Minutes." All artwork is
original CSS gradient work. Never use GTA or Rockstar assets, logos or art.

## Stack
Vite, React, Tailwind CSS, GSAP with ScrollTrigger. No other UI libraries.

## Rules
1. Every value on the page comes from content.md and src/content.js.
   Never hardcode a name, link, stat or project in a component.
2. Layout first, motion second. If something looks off, measure before
   changing animation code.
3. Motion: loader intro, hero poster pieces fly in, pinned hero scrolls
   away and scales down, sections fade in where the previous fades out,
   cursor glow follows the mouse. Respect prefers reduced motion.
4. The Interview AI Platform live link is always
   https://ai-interview-preparation-chi.vercel.app/
   The old dun Vercel link is dead. Never use it.
5. Before pushing, delete any local references folder. It is not part of
   the app.
6. At the end of every task, update the Progress section below.
