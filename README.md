# Satya Sampath Kumar, Portfolio

Cinematic portfolio inspired by the GTA VI promo page workflow from JavaScript
Mastery, rebuilt with original CSS artwork and Satya's real content.

Live site: (Vercel link added after deploy)
Code: https://github.com/SATYA-916/portfolio

## Stack
Vite, React, Tailwind CSS, GSAP with ScrollTrigger.

## Content
All names, links, stats and projects live in content.md and src/content.js.
Edit there first, then sync the UI. The project briefing for coding agents
lives in agents.md.
